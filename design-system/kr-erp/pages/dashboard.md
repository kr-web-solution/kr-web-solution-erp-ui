# Dashboard — page overrides

## Structure

1. Greeting + date (quiet)  
2. KPI row ≤ 4 (pipeline value, open deals, overdue invoices, active projects)  
3. **Work queue** (primary): “Needs you” — stage blockers, unpaid, delayed delivery  
4. Secondary: recent activity timeline (collapsed by default on mobile)

## Anti-pattern

No marketing hero, no large empty chart without a work list above it.
