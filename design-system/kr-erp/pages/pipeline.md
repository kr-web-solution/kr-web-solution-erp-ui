# Pipeline — page overrides

Overrides `MASTER.md` for sales stages 01–05.

## Structure

1. Board header: title + legend (current / done) + New enquiry CTA  
2. Five equal columns; column header = stage code + count  
3. Card: client, value (tabular), age, owner avatar — max 4 lines  
4. Detail: sticky stage rail + stage-specific workspace (upload, checklist, money)

## Color

- Column wash: `#FEF6D8` at low opacity for active stages only  
- Current stage chip: red fill or yellow number  
- Advance CTA: yellow `#FADC59` on ink text  
- Progress bar: red → yellow gradient OK on sales path only

## Density

- Column padding `10–12px`; card gap `8px`  
- Prefer horizontal scroll of columns on &lt;1280px over wrapping

## Hands-on

- Every card click opens the stage that needs work, not a generic overview  
- Upload + View for enquiry/quotation must stay one-click from the stage panel  
- Onboarding: yellow handoff CTA to Project is the only hero action
